# discord-transcriber

<div dir="rtl">

```js
import { createTranscript } from 'discord-transcriber';

const transcript = await createTranscript(channel);

// ملف واحد في كل رسالة: حد الرفع في ديسكورد يسري على الطلب كاملًا.
for (const file of transcript.files) {
  await logChannel.send({ files: [file] });
}
```

## ماذا تعرض النسخة

كل شيء، بالطريقة التي يعرضه فيها ديسكورد:

- الرسائل بماركداون ديسكورد الكامل — العناوين، والنص الصغير `-#`، والقوائم المتداخلة، والاقتباسات، والأكواد، والسبويلر (ينكشف بالضغط) — مع الإيموجي المخصص والمنشنات محلولة بأسمائها الحقيقية
- الردود مع روابط قفز تعمل، وتجميع الرسائل تمامًا كما في التطبيق
- الرسائل المعاد توجيهها (Forwarded)، مع سطر مصدر قابل للضغط يقفز للرسالة الأصلية داخل الملف أو يفتحها في ديسكورد
- المرفقات — الصور معروضة، والصوت والفيديو بمشغلات، وبقية الملفات كبطاقات تنزيل
- الإيمبد الغني، والأزرار، والقوائم المنسدلة
- تخطيطات Components V2: الحاويات والأقسام وعروض النص ومعارض الوسائط والملفات والفواصل
- سطر أوامر السلاش («Eissa used /close»)، والتفاعلات، والملصقات
- بطاقات الثريد باسم الثريد وعدد رسائله ومعاينة آخر رسالة فيه
- أحداث النظام (التثبيت، الانضمام، البوست)، وعلامات التعديل والتثبيت، وفواصل الأيام

كلها بألوان ديسكورد ومسافاته وخطوطه.

## لماذا هذه الحزمة

- **تطابق ديسكورد تمامًا.** التصميم مأخوذ من تطبيق ديسكورد نفسه، حتى أدق التفاصيل.
- **آمنة بالتصميم.** كل محتوى الرسائل يُهرَّب قبل أن يصل إلى HTML، وكل ملف يحمل سياسة أمان محتوى (CSP) صارمة: لا يعمل أي سكربت غير سكربت الملف نفسه، والصور والوسائط تُحمَّل من خوادم ديسكورد فقط. المحتوى الخبيث لا يستطيع التنفيذ ولا الاتصال بالخارج.
- **ملف واحد مكتفٍ بذاته.** لا استضافة، ولا خدمة خارجية، ولا سكربتات من CDN. الملف يفتح بلا إنترنت ويُطبع بشكل نظيف.
- **تقسيم تلقائي للنسخ الكبيرة.** النسخة التي تتجاوز حد الرفع في السيرفر تصبح عدة ملفات كاملة، كل ملف بحجم يناسب مستوى بوست السيرفر.
- **خفيفة ومكتوبة الأنواع.** discord.js هو الاعتماد الوحيد (نظير). تشحن ESM وCommonJS مع تعريفات TypeScript كاملة.

## التثبيت

</div>

```sh
npm install discord-transcriber
```

<div dir="rtl">

تتطلب Node.js 20+ و discord.js v14.19+ (اعتماد نظير).

> **⚠️ صلاحية Message Content مطلوبة.** بدون صلاحية **Message Content** المميزة يحجب ديسكورد `content` و`embeds` و`attachments` و`components` من سجل الرسائل، فتصل كل رسالة لم يكتبها بوتك فارغة — وتظهر النسخة فقاعات خاوية بلا أي خطأ. فعّلها من صفحة **Bot** في [بوابة المطورين](https://discord.com/developers/applications) **وأعلنها** في العميل:
>
> ```js
> new Client({ intents: [GatewayIntentBits.Guilds, GatewayIntentBits.MessageContent] });
> ```

## الاستخدام

### الاستخدام الأساسي

</div>

```js
import { createTranscript } from 'discord-transcriber';

const transcript = await createTranscript(channel, {
  limit: 2000,             // أحدث ٢٠٠٠ رسالة؛ الافتراضي: الكل
  filename: 'ticket-1042', // الافتراضي: transcript-<اسم القناة>
});

transcript.files;        // AttachmentBuilder[] جاهزة لـ channel.send({ files })
transcript.parts;        // { filename, content: Buffer, partNumber, ... }[]
transcript.messageCount; // كم رسالة جُمعت
transcript.truncated;    // true إذا كانت القناة تحوي أكثر من `limit`
transcript.byteSize;     // الحجم الكلي لكل الأجزاء
```

<div dir="rtl">

تعمل مع أي قناة نصية داخل سيرفر: القنوات النصية وقنوات الإعلانات والثريدات ودردشة القنوات الصوتية وقنوات الستيج.

أرسل ملفًا واحدًا في كل رسالة — حد الرفع في ديسكورد يسري على الطلب كاملًا:

</div>

```js
const [first, ...rest] = transcript.files;
await logChannel.send({ content: 'Transcript', files: [first] });
for (const file of rest) await logChannel.send({ files: [file] });
```

<div dir="rtl">

أو احفظ الملفات على القرص:

</div>

```js
import { writeFile } from 'node:fs/promises';
for (const part of transcript.parts) {
  await writeFile(part.filename, part.content);
}
```

### هويتك الخاصة

المحادثة تحتفظ دائمًا بمظهر ديسكورد. أما الإطار حولها — الترويسة ولون التمييز والتذييل — فهو لك:

</div>

```js
await createTranscript(channel, {
  brand: {
    name: 'CastCord Support',           // سطر بارز فوق اسم القناة
    accentColor: '#9146ff',             // لون الإطار؛ الافتراضي أزرق ديسكورد
    footerText: 'Generated by CastCord Helper',
    logoSvg: '<svg class="brand-mark" ...>...</svg>', // شعارك، في الترويسة والتذييل
  },
});
```

<div dir="rtl">

> **ملاحظة أمنية:** `logoSvg` يُضمَّن كما هو حتى يبقى الملف مكتفيًا بذاته. مرّر فقط ماركب كتبته بنفسك — لا مدخلات مستخدمين أبدًا.

### لوحة التفاصيل

سجّل حقائق ليست جزءًا من المحادثة نفسها — من فتح التذكرة، ولماذا أُغلقت، وماذا أجاب النموذج:

</div>

```js
await createTranscript(channel, {
  metadata: [
    { label: 'القسم', value: 'الدعم الفني', icon: 'tag' },
    { label: 'فتحها', value: '7sO (7so)', icon: 'person' },
    { label: 'أغلقها', value: 'Eissa (eissa)', icon: 'shield' },
    { label: 'سبب الإغلاق', value: 'تم الحل.', icon: 'note', wide: true },
  ],
  metadataTitle: 'التفاصيل', // عنوان اللوحة — اكتبه بأي لغة
  notices: ['صُدِّرت لمراجعة الإشراف.'],
});
```

<div dir="rtl">

الأيقونات المتاحة: `tag` · `text` · `person` · `shield` · `people` · `clock` · `lock` · `note` · `chat`، وأضف `wide: true` لتعطي القيمة الطويلة صفًا كاملًا لوحدها.

### كل الخيارات

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `limit` | `number` | كل الرسائل | يُحتفظ بالأحدث، وإشعار داخل الملف يوضح الاقتطاع. |
| `filter` | `(m) => boolean` | إبقاء الكل | مثل `(m) => !m.author.bot`؛ يُطبَّق قبل التجميع ومعاينات الردود فتبقى المحادثة متماسكة. |
| `maxFileBytes` | `number \| 'auto'` | `'auto'` | أقصى حجم للملف الواحد؛ `'auto'` يقرأ مستوى بوست السيرفر. |
| `filename` | `string` | `transcript-<القناة>` | اسم الملف الأساسي؛ الأجزاء تأخذ لاحقة `-part2of3`. |
| `title` | `string` | `#القناة · السيرفر` | عنوان تبويب المتصفح. |
| `favicon` | `'guild' \| 'none' \| رابط` | `'guild'` | أيقونة التبويب؛ الرابط المخصص يجب أن يكون على خوادم ديسكورد. |
| `brand` | كائن | محايد | الاسم والشعار واللون والتذييل — انظر أعلاه. |
| `metadata` | مصفوفة | لا شيء | لوحة التفاصيل — انظر أعلاه. |
| `metadataTitle` | `string` | `Details` | عنوان اللوحة. |
| `notices` | `string[]` | لا شيء | إشعارات إضافية فوق المحادثة. |

### متقدم: اجمع الآن واعرض لاحقًا

الحزمة طبقتان مستقلتان: `collectMessages` تحوّل القناة إلى بيانات عادية، و`renderTranscript` تحوّل تلك البيانات إلى ملفات HTML بلا أي اتصال بديسكورد — فتستطيع تخزين البيانات في أي مكان وعرضها متى شئت:

</div>

```js
import {
  collectMessages,     // قناة -> بيانات عادية (رسائل، منشنات، اقتطاع)
  collectFromMessages, // رسائل تملكها مسبقًا -> نفس البيانات
  renderTranscript,    // بيانات عادية -> ملفات HTML (بلا ديسكورد)
} from 'discord-transcriber';

const collected = await collectMessages(channel, { limit: 500 });

// ...خزّن `collected` في أي مكان، ثم لاحقًا:
const parts = renderTranscript(
  {
    guildName: channel.guild.name,
    channelName: channel.name,
    messages: collected.messages,
    mentions: collected.mentions,
    truncated: collected.truncated,
    generatedAt: new Date(),
  },
  { maxBytes: 8 * 1024 * 1024 },
);
```

<div dir="rtl">

الجامع يحل أيضًا المنشنات التي يحذفها ديسكورد من حمولة الرسالة (المنشنات المكتومة عبر `allowed_mentions` — وهي شائعة في إعلانات البوتات)، فيظهر `<@id>` باسم صاحبه لا برقم.

## ملاحظات وحدود

- **صلاحية Message Content مطلوبة** (انظر التثبيت أعلاه). الحزمة لا تستطيع كشف غيابها — ديسكورد يعيد الرسائل فارغة بلا خطأ.
- **التوقيتات بتوقيت UTC**، مصاغة كما صاغها ديسكورد لحظة إنشاء النسخة (`4:30 AM`، `Yesterday at…`)؛ واللحظة الدقيقة في تلميح كل توقيت.
- **الوسائط تُحمَّل من خوادم ديسكورد.** روابط المرفقات تنتهي صلاحيتها بعد فترة، فقد تتوقف الصور والمشغلات في النسخ القديمة عن العمل. نص المحادثة غير متأثر — فهو داخل الملف.
- **قنوات الخاص (DM) غير مدعومة** — الجامع يقرأ سياق السيرفر (الألقاب، ألوان الرتب، مستوى البوست).
- الملف يحوي سكربتًا واحدًا فقط وظيفته جعل القفز إلى الردود سلسًا. مع تعطيل الجافاسكربت كل شيء يستمر بالعمل.

## استخدام مسؤول

النسخة تحتوي رسائل أعضاء سيرفرك. متى ما خزّنها بوتك أو شاركها صارت تلك البيانات مسؤوليتك وفق [شروط خدمة المطورين](https://discord.com/developers/docs/policies-and-agreements/developer-terms-of-service) و[سياسة مطوري ديسكورد](https://discord.com/developers/docs/policies-and-agreements/developer-policy):

- اذكر النسخ في سياسة خصوصية بوتك، حتى يعرف الأعضاء أن رسائلهم قد تُؤرشف.
- لا تشارك النسخة إلا مع من كان يستطيع قراءة القناة أصلًا — نسخة التذكرة تخص الطاقم وأطراف التذكرة.
- احذف النسخ المخزّنة متى ما طلب منك عضو أو سيرفر ذلك.
