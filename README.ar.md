# discord-transcriber

<div dir="rtl">

نسخ HTML مطابقة لديسكورد بكسل-بكسل، قائمة بذاتها، لأي قناة ديسكورد.

**[Read this in English →](https://github.com/eissa99/discord-transcriber/blob/main/README.md)**

استدعاء واحد يحوّل القناة إلى ملفات HTML مستقلة تعيد إنتاج المحادثة **كما ظهرت في ديسكورد** — لا تقريبًا لها: تجميع الرسائل، الردود مع روابط القفز، المنشنات محلولة بأسمائها، ماركداون الرسائل كاملًا، الإيموجي المخصص، المرفقات، الإيمبد بشبكة الحقول ذات الاثني عشر عمودًا، الأزرار والقوائم، **تخطيطات Components V2** (الحاويات والأقسام وعروض النص ومعارض الوسائط والملفات والفواصل)، سطر استدعاء أوامر السلاش («Alice used /close»)، مشغلات صوت وفيديو مضمّنة، مؤشرات الثريد، التفاعلات، الملصقات، أحداث النظام (التثبيت والانضمام والبوست)، علامات التعديل والتثبيت وفواصل الأيام — كلها بألوان ديسكورد ومسافاته وخطوطه.

</div>

```ts
import { createTranscript } from 'discord-transcriber';

const transcript = await createTranscript(channel);
// ملف واحد في كل رسالة: حد الرفع يسري على الطلب كاملًا،
// وكل جزء محسوب حجمه على ذلك الحد.
for (const file of transcript.files) {
  await logChannel.send({ files: [file] });
}
```

## لماذا هذه الحزمة

- **عرض مطابق.** منطقة المحادثة مصممة بقيم مأخوذة من عميل ديسكورد نفسه، حتى انحناء خط الرد ونافذة تجميع الرسائل (سبع دقائق) ووسم APP. النسخة تُقرأ كأنها القناة نفسها.
- **آمنة بالبناء، لا بالحذر.** محتوى الرسائل بيد المرسِل، لذلك لا يمر نص خام إلى HTML أبدًا: النص يُجزّأ أولًا وكل جزء نصي يُهرَّب لحظة إخراجه. وفوق ذلك يعلن المستند سياسة أمان محتوى (CSP) تمنع كل السكربتات إلا سكربت المستند نفسه (مقبول ببصمة SHA-256، لا بـ`unsafe-inline`)، وتحصر الصور في خوادم ديسكورد، وتمنع النماذج والإطارات والخطوط الخارجية. حتى الخطأ البرمجي لا يستطيع تنفيذ محتوى أو الاتصال بطرف ثالث.
- **ملفات قائمة بذاتها، بلا خدمة خلفها.** التنسيق مضمّن، والأيقونات SVG مضمّنة، ولا يُجلب شيء عند الفتح سوى الصور من خوادم ديسكورد. لا استضافة ولا عارض ولا رابط يموت. الملف يعمل بلا إنترنت ويُطبع بشكل نظيف.
- **تقسيم بدل الفشل.** النسخة التي تتجاوز حد الرفع في السيرفر تُقسَّم إلى عدة ملفات HTML كاملة مستقلة عند حدود الرسائل — والحجم يُحسب تلقائيًا من مستوى البوست.
- **طبقات مفصولة وقابلة للاختبار.** `collectMessages` تحوّل القناة إلى بيانات عادية، و`renderTranscript` تحوّل البيانات إلى ملفات. خزّن البيانات واعرضها لاحقًا بلا اتصال بديسكورد. الحزمة تشحن ESM + CJS مع تعريفات TypeScript كاملة.

## التثبيت

</div>

```sh
npm install discord-transcriber
```

<div dir="rtl">

تتطلب Node.js 20+ و discord.js v14.19+ (كاعتماد نظير).

> **⚠️ صلاحية Message Content مطلوبة.** ديسكورد يحجب `content` و`embeds` و`attachments` و`components` من سجل الرسائل عن أي تطبيق بدون صلاحية **Message Content** المميزة. بدونها تصل كل رسالة لم يكتبها بوتك فارغة وتظهر النسخة فقاعات خاوية — بلا أي خطأ. فعّلها من صفحة **Bot** في [بوابة المطورين](https://discord.com/developers/applications) **وأعلنها** في العميل:
>
> ```ts
> new Client({ intents: [GatewayIntentBits.Guilds, GatewayIntentBits.MessageContent] });
> ```

## الاستخدام

### المسار المختصر

</div>

```ts
import { createTranscript } from 'discord-transcriber';

const transcript = await createTranscript(channel, {
  limit: 2000,             // أحدث ٢٠٠٠ رسالة؛ الافتراضي: الكل
  filename: 'ticket-1042', // الافتراضي: transcript-<اسم القناة>
});

transcript.files;        // AttachmentBuilder[] جاهزة لـ channel.send({ files })
transcript.parts;        // { filename, content: Buffer, ... }[]
transcript.messageCount; // عدد الرسائل المجموعة
transcript.truncated;    // true إذا كانت القناة تحوي أكثر من `limit`
```

<div dir="rtl">

تعمل مع أي قناة نصية داخل سيرفر: القنوات النصية، قنوات الإعلانات، الثريدات، ودردشة القنوات الصوتية.

أرسل ملفًا واحدًا في كل رسالة — حد الرفع في ديسكورد يسري على الطلب كاملًا:

</div>

```ts
const [first, ...rest] = transcript.files;
await logChannel.send({ content: 'Transcript', files: [first] });
for (const file of rest) await logChannel.send({ files: [file] });
```

<div dir="rtl">

### تخصيص الهوية

المحادثة تحتفظ دائمًا بمظهر ديسكورد. أما إطار المستند حولها — الترويسة ولون التمييز والتذييل — فهو لك:

</div>

```ts
await createTranscript(channel, {
  brand: {
    name: 'CastCord Support',           // سطر بارز فوق اسم القناة
    accentColor: '#9146ff',             // لون الإطار؛ الافتراضي أزرق ديسكورد
    footerText: 'Generated by CastCord Helper',
    logoSvg: '<svg class="brand-mark" ...>...</svg>', // شعار SVG مضمّن
  },
});
```

<div dir="rtl">

> **ملاحظة أمنية:** `logoSvg` يُضمَّن كما هو حتى يبقى الملف قائمًا بذاته. مرّر فقط ماركب كتبته بنفسك — لا مدخلات مستخدمين أبدًا.

### لوحة التفاصيل

سجّل الحقائق التي لا تظهر في المحادثة نفسها — من فتح التذكرة، ولماذا أُغلقت، وإجابات النموذج. العناوين تقبل العربية:

</div>

```ts
await createTranscript(channel, {
  metadata: [
    { label: 'القسم', value: 'الدعم الفني', icon: 'tag' },
    { label: 'فتحها', value: 'Alex (alex)', icon: 'person' },
    { label: 'سبب الإغلاق', value: 'تم الحل.', icon: 'note', wide: true },
  ],
  metadataTitle: 'التفاصيل',
});
```

<div dir="rtl">

الأيقونات المتاحة: `tag` · `text` · `person` · `shield` · `people` · `clock` · `lock` · `note` · `chat`، و`wide: true` تعطي القيمة الطويلة الصف كاملًا.

### كل الخيارات

| الخيار | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `limit` | `number` | كل الرسائل | يُحتفظ بالأحدث، وإشعار يوضح الاقتطاع. |
| `filter` | `(m) => boolean` | إبقاء الكل | مثل `(m) => !m.author.bot`؛ يُطبَّق قبل التجميع وملخصات الردود فتبقى المحادثة متماسكة. |
| `maxFileBytes` | `number \| 'auto'` | `'auto'` | أقصى حجم للملف الواحد؛ `'auto'` يحسبه من مستوى بوست السيرفر. |
| `filename` | `string` | `transcript-<القناة>` | اسم الملف الأساسي؛ الأجزاء تأخذ لاحقة `-part2of3`. |
| `title` | `string` | `#القناة · السيرفر` | عنوان المستند. |
| `favicon` | `'guild' \| 'none' \| رابط` | `'guild'` | أيقونة التبويب؛ الرابط المخصص يجب أن يكون على خوادم ديسكورد وإلا يُسقط. |
| `brand` | `TranscriptBrand` | محايد | الاسم والشعار واللون والتذييل. |
| `metadata` | `TranscriptMetadataEntry[]` | لا شيء | لوحة التفاصيل فوق المحادثة. |
| `metadataTitle` | `string` | `Details` | عنوان اللوحة. |
| `notices` | `string[]` | لا شيء | إشعارات إضافية. |

## ملاحظات وحدود

- **صلاحية Message Content مطلوبة** (انظر التثبيت أعلاه). الحزمة لا تستطيع كشف غيابها — ديسكورد يعيد الرسائل فارغة بلا خطأ.
- **التوقيتات بتوقيت UTC** ومصاغة كما صاغها ديسكورد لحظة التوليد؛ اللحظة الكاملة في تلميح كل توقيت. السجل لا يعيد صياغة نفسه مع مرور الزمن.
- **الوسائط تُعرض من خوادم ديسكورد مباشرة.** روابط المرفقات تحمل توقيعات تنتهي صلاحيتها، فقد تتوقف صور النسخ القديمة عن الظهور. نص المحادثة غير متأثر — فهو داخل الملف.
- **قنوات الخاص (DM) غير مدعومة** — الجامع يقرأ سياق السيرفر (الألقاب، ألوان الرتب، مستوى البوست).
